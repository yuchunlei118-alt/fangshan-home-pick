校额到校 是什么 · 一张图看懂

答应 整理 · 2026-10-07 · 数据口径：北京教育考试院《2025年初中学校校额到校分配名额》
一句话：优质高中拿出一部分名额，按"初中学校"分下去，孩子在自己学校内部排名竞争就能进好高中，不用跟全区牛校拼总分。

① 名额怎么流下来的

优质高中房山中学 / 良乡中学 / 北师大良乡附中 / 四中房山 / 理工附实验 …
→
拿出 50%+ 招生计划定向分配到各初中（不再全区统一抢）
→
落到每所初中按毕业生规模等分 → 就是表里那列"名额"
→
校内竞争你在本校排进前 N 名（且达线）→ 用更低的分数进优质高中
关键区别：统招＝全房山一起排名抢；校额到校＝只在你们一个学校里排名抢 → 竞争范围小得多，所以录取分通常低于该校统招线。

② 用你家门口的学校当例子（真数）

瑞雪春堂对口的「海淀进校附房山实验学校」＝ 53 个名额，拆开是这样：
去哪个优质高中给多少名额实际含义
房山中学11这 4 所各给 11–10 个 → 校内达线（≥430分、综评B）且志愿报了该校的学生里，按成绩从高到低录满。
注：不是"全校前11名"——前面的人若走统招去更好的学校，名额会顺延给后面的同学
良乡中学11
北京师范大学良乡附属中学11
房山实验中学10
首都师范大学附属中学实验学校4还要跟本校同学抢，名次越前越稳
北京四中房山分校4跨档到四中房山的名额（含金量最高）
北京理工大学附属实验学校2同上，名额最少
合计53＝全校 53 个人走这条通道
名额最多的那所（北京四中房山分校）是 105 个：房山中学21／良乡中学21／北师大良乡附中21／房山实验21＋四中房山本校8／首师大附中实验7／北理工4 等。

③ 门槛 4 条（缺一条就没资格）

1. 京籍 / 非京籍九类人
普通非京籍不在此列
2. 同一初中连续三年学籍
转学/中途插班会断
3. 中考 ≥ 430 分
2025年新标准
4. 综合素质评价 B 等以上
另外：往届生、1+3 项目录取后退出、外省回京报考、回户籍报考 —— 都不能参加。

④ 这条对你家意味着什么

🔴 你家户口在珠海横琴 → 属普通非京籍 → 这 53 个名额、这 105 个名额，都用不上。
它是"京籍孩子的升学通道"地图，对你是信息不是路径。能真正用上的只有：小学就近入学（走四证＋教委统筹），以及落户北京的长期规划。

⑤ 所以这列数字该怎么读（别读错）

名额多 ≠ 学校质量高。名额是按毕业生规模等分下来的 → 名额多主要说明"学校盘子大"。
• 想比学校好不好 → 看中考平均分 / 优秀率（目前只有四中房山公开：2026 平均 442.88、优秀率 68.87%、全区第3、4名出自该校）
• 想比上升通道宽不宽 → 看这列名额（数字越大，校内"够得着优质高中"的人越多）
• 2025 年是北京所有初中首次全覆盖校额到校的第一年，名额普遍增加 → 全房山每所初中都有，不再是"只有差校才有"
